# Nouveautés

## Foot Live sur Android

- Installez désormais Foot Live sur Android avec l'APK téléchargeable.
- Consultez les scores, le classement et les évolutions depuis une interface mobile.
- Recevez une alerte lorsqu'une nouvelle version Android est disponible.

## Évolutions de célébrité exactes

- Découvrez les plus fortes hausses et baisses de célébrité entre deux saisons.
- Comparez l'évolution moyenne de chaque poste.
- Filtrez les résultats par poste et consultez l'âge des joueurs lorsqu'il est disponible.

## Mises à jour Windows

- Une note présente les nouveautés une seule fois après chaque mise à jour.
